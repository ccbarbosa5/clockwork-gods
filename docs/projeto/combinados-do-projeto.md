# Combinados do projeto Clockwork Gods

Regras de trabalho definidas pelo dono do projeto (Caio). Migradas do claude.ai em 24 nov. 2026; o resumo operacional está no `CLAUDE.md` da raiz.

## Autorizações permanentes do usuário

- **GitHub:** pode juntar na `main` (o que publica no itch.io) sem pedir confirmação, sempre que `tools/run_tests.sh` terminar com TUDO OK (2026-11-09).
- **Arquivos novos:** salvar arquivos e documentos novos não precisa de permissão; avisar em uma linha o que foi salvo (2026-11-09). Continuam exigindo aprovação: decisões de conteúdo (marcar algo como DEFINIDO na lore), apagar arquivos e sobrescrever arquivos aprovados.
- **Balanceamento:** ajuste autônomo dentro das regras de docs/projeto/balanceamento.md (2026-11-11).

## Documentação de lore e arte

Sempre que for criado algo novo no jogo que precise de lore ou de imagem (herói, habilidade, arena, objeto, efeito, interface, evento), criar um documento explicando esse item.

O documento deve:

- Ser autossuficiente.
- Extrair as informações do código e das decisões já tomadas, sem inventar.
- Marcar com "A DEFINIR" o que não existe ou não foi decidido.
- Usar números reais do jogo (pixels na resolução base 1280 × 720, segundos, quantidades).
- Para lore, separar o que é DEFINIDO, PROPOSTA, A DEFINIR e MITO (mitologia grega original, só inspiração).
- Ser escrito em português, de forma clara e direta.
